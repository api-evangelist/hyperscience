# Hyperscience (hyperscience)

Hyperscience provides enterprise-grade intelligent document processing (IDP) via the Hypercell platform — automated extraction, classification, GenAI processing and human-in-the-loop validation. Industry/use-case modules include Hypercell for Freight Pay, GenAI and SNAP. FedRAMP High authorised; cloud and on-prem deployments.

**APIs.json:** [apis.yml](apis.yml)

## APIs
- **Hyperscience REST API** — per-tenant base URL — submit documents, retrieve extraction results, manage Flows and human-review queues. Each customer receives a dedicated tenant URL. [Docs](https://www.hyperscience.ai/products/api/).

## OpenAPI
Hyperscience does not publish a public OpenAPI/Swagger document — API documentation is delivered to enterprise customers behind authentication; pipeline did not retrieve a spec into `openapi/`.
